# Kampüs Etkinlikleri - Vize Projesi

## Canlı Proje Adresi
- Vercel Canlı Linki: https://asiyesudeceylan-frontend.vercel.app

## Kurulum ve Çalıştırma
Projeyi kendi bilgisayarınızda çalıştırmak için:
1. `git clone` ile projeyi indirin.
2. `cd frontend` klasörüne gidin.
3. `npm install` komutu ile bağımlılıkları yükleyin.
4. `npm run dev` komutu ile projeyi başlatın.

## Route Listesi
- `/` -> Ana Sayfa
- `/events` -> Tüm Etkinlikler
- `/events/:id` -> Etkinlik Detay Sayfası
- `/admin` -> Yönetim Paneli
- `/admin/new` -> Yeni Etkinlik Ekleme
- `/admin/:id/edit` -> Etkinlik Düzenleme
- `/login` -> Giriş Sayfası
